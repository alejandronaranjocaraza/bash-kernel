# Hard Links

- Each file is points to an inode (chain of disk blocks) that contains the data in a file
- Hard links create new files pointing to the same inode (underlying data)

## Disadvantages of hard links

- cannot span physical devices
- cannot reference directories

## Refs

ln [my_file] [target_name]

example: ln my_file my_new_file_hard_link

# Symbolic Links

Text files that point to another file.

- Can point via relative or absoule path

## Refs

ln -s [absolute_path_to_my_file] [target_file]

ln -s [path_relative_to_target] [target_file]

# Removing Original File

- Symbolic link breaks (points to the file)
- Hard link remains intact (point to inode)

# Must Know Commands

$ ln fun fun-hard
    create hard link
$ ls -li
    long format + show inode number
$ ln -s ../fun dir1/fun-sym
    create symbolic link (relative reference
