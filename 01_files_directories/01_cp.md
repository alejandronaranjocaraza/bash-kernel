cp item1 item2; -- copies item1 into item2

cp item ... directory; -- copies item into file with same name inside directory

- a | --archive: copy files with all their attributes
- i | --interactive: propmt before overwriting
- r | --recursive: copy directory and all its contents
- u | --update: only copy files that don't exist or are newer than the trager directory
- v | --verbose: display informative messages as the copy is performed
