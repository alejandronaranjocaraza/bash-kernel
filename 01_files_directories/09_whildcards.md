# List of Common Willdcards

- * : Matches any characters
- ? : Matches one character
- [characters] : Matches any character that is a member of set characters
- [!characters] : Matches any character that is not a member of set characters
- [[class]] : Matches any character of specificied class

# List of Common Classes

- [:alnum:] : Matches any alphanumeric
- [:alpha:] : Matches any alphabetic character
- [:digit:] : Matches any numeral
- [:lower:] : Matches any lowercase letter
- [:upper:] : Matches any uppercase letter
