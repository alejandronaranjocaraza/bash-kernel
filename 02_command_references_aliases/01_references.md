# What Commands Are

One of four things:

- Executable program (/usr/bin/)

- Shell built in

- Shell functions (Scripts configured into environment)

- Alias (Built from other commands)

# Reference Commands

- type: indicate how command is interpreted

- which: identifiy which program will be executed

- help: get help for shell builtins

- man: display command manual page

- apropos: display list of appropriate commands

- info: display command info entry

- whatis: display one line description
